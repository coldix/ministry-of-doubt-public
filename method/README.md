# Methodology

These are the public methodology documents for The Ministry of Doubt.

## Documents

- **`truth-protocol.md`** — The canonical evidence and reasoning protocol. Start here. Defines claim IDs, confidence levels, the evidence ledger, source independence, falsification conditions and publication states.

- **`working-method.md`** — The practical working method: how claims are formed, how sources are weighted, how the ledger is updated, and how confidence changes when new evidence arrives.

- **`worked-examples.md`** — Annotated examples applying the protocol to realistic scenarios.

## Purpose

The Ministry of Doubt publishes its methodology so that any reader can:

1. Understand how a claim was assessed
2. Identify which evidence supports or contradicts it
3. Know what evidence would change the assessment (falsification condition)
4. Challenge the methodology itself, not just individual findings

The governing principle: **Don't trust the Ministry. Check the Ministry.**
