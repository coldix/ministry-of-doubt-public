# Worked method examples

Non-political and short illustrations for Chapters 1–2. Expand as needed. Do not use these as chapter drafts.

## 1. Model vs reality (Ch.1)

**Claim:** “This bathroom scale says I weigh 82.0 kg, so I weigh exactly 82.0 kg.”

| Element | Notes |
|---------|--------|
| Model | Digital scale reading = true mass |
| Hidden assumptions | Calibration; flat floor; same clothing; no battery drift; single sample |
| Discriminating test | Second calibrated instrument; repeat measures; change surface |
| Lesson | Precise output can still be wrong if the instrument model is wrong. **GIGO.** |

## 2. Local proportional update (Ch.2)

**Non-political claim:** “The 8:15 ferry is always on time.”

Prior (thin): **POSSIBLE / moderate** — ferries often run late; one route unknown.

| Observation | Update |
|-------------|--------|
| One day late 12 min | Slightly lowers “always on time”; does not prove “always late” |
| Official timetable PDF | Source reliability for schedule intent, not for actual performance |
| 20 consecutive GPS logs late | Stronger posterior against “always on time” |
| One viral anecdote | Low weight; independence n = 1 |

**Independence:** Twenty tweets citing the same delayed passenger are one line, not twenty.

## 3. Source-independence audit checklist

For any important claim:

1. Write the claim in one sentence.  
2. List every source you would cite.  
3. Trace each to earliest origin you can find.  
4. Assign an **independence_group** ID (same memo / same leak / same presser = same group).  
5. Count **n = number of distinct groups**, not number of URLs.  
6. If n = 1, say so explicitly in the dossier.

## 4. Process vs object-level

| Fact pattern | Process verdict | Object-level still open? |
|--------------|-----------------|---------------------------|
| Agency destroys backups after litigation hold | Serious process failure | Does not alone prove the plaintiff’s theory of the underlying debt |
| Scale was uncalibrated | Measurement process bad | True weight still unknown without better measure |

## 5. Base rates (sketch)

Institutions produce millions of statements. Some will be wrong or dishonest. That raises the **possibility** of conspiracy or failure; it does not raise every specific allegation to PROBABLE. Update **per claim, actor, and domain**.
